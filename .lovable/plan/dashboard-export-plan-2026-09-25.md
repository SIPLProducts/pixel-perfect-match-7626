# Dashboard export plan

## What will change
- Add **Export CSV** and **Export PDF** actions beside the dashboard filters.
- Export only the assets matching the currently selected category, location, status, and installation-age filters.
- Include the current dashboard summary: asset count, acquisition cost, current value, average equipment age, active/inactive split, and attention counts.
- Include chart data summaries for equipment-life bands and asset status, plus the complete filtered asset list.
- Use clear filenames and show a friendly message when no assets match.

## PDF layout
- Create a branded Sharvi Asset360 report with the applied-filter summary, KPI overview, chart summaries, attention items, and a paginated asset table.
- Keep the report readable for both small and large filtered result sets.

## Validation
- Verify both downloads, confirm their contents reflect a changed filter, and check the dashboard on desktop and mobile.
- Keep the existing standalone asset-register exports unchanged.
